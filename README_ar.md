## ما هو Exameow؟

**Exameow (过了喵)** هو **مولد أسئلة امتحانات مفتوح المصدر يعمل بالذكاء الاصطناعي** يقوم بتحويل المواد الدراسية إلى أسئلة امتحانات عالية الجودة في ثوانٍ معدودة. قم بتحميل ملفات PDF أو مستندات Word أو شرائح PowerPoint أو الصور أو النصوص — يقرأ الذكاء الاصطناعي المحتوى ويقوم بإنشاء أسئلة اختيار من متعدد (إجابة واحدة / إجابات متعددة)، وصواب/خطأ، وإكمال الفراغات، وإجابات قصيرة مصممة حسب احتياجاتك.

على عكس أدوات إنشاء الاختبارات الأخرى التي تتطلب إنشاء حسابات أو اشتراكات مدفوعة أو ترسل بياناتك إلى السحابة، فإن Exameow يعتمد على **الأولوية للمحلي والتركيز على الخصوصية (Local-first)**. تظل بنوك الأسئلة وسجلات التدريب وتاريخ الأسئلة الخاطئة على جهازك. تعمل تطبيقات سطح المكتب للهاتف المحمول **بدون اتصال بالإنترنت تمامًا** باستخدام مفتاح API الخاص بك متوافق مع OpenAI (مثل OpenAI أو DeepSeek أو Qwen أو GLM أو أي نموذج مستضاف ذاتيًا).

للمعلمين والمدربين، يتضمن Exameow **نظام امتحانات عبر الإنترنت** مدمجًا — قم بنشر الامتحانات من بنوك الأسئلة المحلية الخاصة بك، وشارك رمزًا مكونًا من 6 أرقام، وينضم الطلاب من أي متصفح. يتضمن التقييم الفوري، ولوحة تحكم المعلم، وحماية ضد الإساءة. يمكنك استضافة النظام بالكامل ذاتيًا باستخدام أمر Docker واحد.

جربه عبر الإنترنت: **[exam.superagentparty.com](https://exam.superagentparty.com/)**

يعمل العرض التوضيحي على Cloudflare Workers باستخدام الفئة المجانية من Workers AI:

- ⏳ **الحصة اليومية محدودة** — يتم إعادة تعيين حصة الذكاء الاصطناعي المجانية من Cloudflare يوميًا
- 📄 **حد نافذة السياق** — سيتم اقتطاع المستندات الكبيرة لكي تتناسب مع نافذة سياق النموذج

لاستخدام غير محدود، قم بالاستضافة الذاتية باستخدام Docker أو استخدم تطبيقات سطح المكتب/الهاتف المحمول مع مفتاح API الخاص بك.

## الميزات

### ✨ إنشاء الأسئلة بالذكاء الاصطناعي — قم بتحميل الملفات واحصل على أسئلة الامتحانات

يدعم Exameow تحليل المواد الدراسية بـ **أكثر من 10 تنسيقات ملفات** — PDF و DOCX و XLSX و PPTX و EPUB و ODT و TXT و CSV و HTML والصور (PNG/JPG/WEBP/GIF/BMP). قم بتحميل ملف واحد أو اسحب وأسقط ملفات متعددة في وقت واحد. يولد الذكاء الاصطناعي الأسئلة عبر **5 أنواع من الأسئلة**: اختيار من متعدد (إجابة واحدة)، اختيار من متعدد (إجابات متعددة)، صواب/خطأ، إكمال الفراغات، وإجابة قصيرة. يمكنك التحكم في عدد الأسئلة لكل نوع، ومستوى الصعوبة (سهل/متوسط/صعب)، ولغة المخرجات، وتصفية المواضيع/الفصول. يتم تقسيم المستندات الكبيرة تلقائيًا وتوليدها على دفعات مع إزالة التكرار. يعمل مع أي API متوافق مع OpenAI — مثل OpenAI أو DeepSeek أو Qwen أو GLM، أو استخدم Cloudflare AI المجاني المدمج في موقع العرض التوضيحي. يمكن تصدير النتائج كملفات XLSX أو CSV.

- **تنسيقات إدخال غنية** — PDF، DOCX، XLSX، PPTX، EPUB، ODT، TXT، CSV، HTML، والصور (PNG/JPG/WEBP/GIF/BMP)، وأي ملف نصي/برمجي؛ تحميل ملفات متعددة بالسحب والإفلات
- **5 أنواع أسئلة** — اختيار من متعدد (إجابة واحدة)، اختيار من متعدد (إجابات متعددة)، صواب/خطأ، إكمال الفراغات، إجابة قصيرة، مع التحكم في العدد لكل نوع
- **تحكم دقيق** — الصعوبة (سهل / متوسط / صعب)، لغة المخرجات، وتصفية المواضيع/الفصول
- **تجميع ذكي (Batches)** — يتم تقسيم المستندات الكبيرة تلقائيًا وإنشاؤها على دفعات مع إزالة الأسئلة المكررة
- **أي API متوافق مع OpenAI** — OpenAI، DeepSeek، Qwen، GLM، إلخ؛ أو استخدم Cloudflare AI المجاني المدمج في موقع العرض التوضيحي
- **تصدير** — تنزيل النتائج كملفات XLSX أو CSV

### 📚 وضع التدريب — ادرس بذكاء وليس بجهد

تحويل الأسئلة الموّلدة إلى جلسات دراسية تفاعلية. تدرب بالتتابع، أو قم بخلط الأسئلة والخيارات عشوائيًا، أو خض امتحانًا تجريبيًا موقوتًا بنماذج أسئلة يتم إنشاؤها تلقائيًا. يتم تتبع الأسئلة الخاطئة تلقائيًا ومراجعتها — أجب عن السؤال بشكل صحيح عدة مرات متتالية وسيتم إزالته من قائمة الأسئلة الخاطئة. التبديل بين وضع الامتحان (الإجابة بدون رؤية الإجابات) ووضع البطاقات التعليمية (الإجابات مرئية). يتم تقييم الأسئلة ذات الإجابات القصيرة بواسطة الذكاء الاصطناعي مقارنة بالإجابات المرجعية مع إمكانية التقييم اليدوي. استيراد وتصدير بنوك الأسئلة عبر XLSX/CSV مع تعيين ذكي للأعمدة.

- **التدريب المتتابع** — استعراض بنك الأسئلة بالترتيب
- **التدريب العشوائي** — خلط الأسئلة والخيارات عشوائيًا لتعزيز الحفظ
- **الامتحان التجريبي** — إنشاء ورقة امتحان عشوائية تلقائيًا من أي بنك أسئلة مع ضبط أعداد الأسئلة حسب النوع
- **مراجعة الأسئلة الخاطئة** — تتبع الأخطاء، والتدرب فقط على ما أخطأت فيه، وملاحظة اختفائها مع تحسن أدائك
- **وضعا الامتحان / البطاقات التعليمية** — الإجابة دون الاطلاع على الإجابة، أو التصفح مع إظهار الإجابات فورًا
- **التصحيح بالذكاء الاصطناعي** — تقييم الأسئلة ذات الإجابات القصيرة بواسطة الذكاء الاصطناعي بناءً على الإجابة المرجعية مع تقديم ملاحظات، مع دعم التصحيح اليدوي
- **إدارة بنوك الأسئلة** — استيراد بنوك الأسئلة من XLSX/CSV مع تعيين الأعمدة الذكي؛ والتصدير في أي وقت

### 📝 الامتحانات عبر الإنترنت — نشر الدعوة للطلاب

قم بتشكيل الامتحانات من بنوك أسئلة محلية متعددة مع تحديد عدد الأسئلة وقيم النقاط لكل نوع. حدد العنوان، ووقت البدء، ومدة الامتحان. شارك **رمزًا مكونًا من 6 أرقام** أو رابط الامتحان — ينضم الطلاب من متصفح أي جهاز دون الحاجة إلى تثبيت أي تطبيق. يحافظ العداد التنازلي المحلي مع التسليم التلقائي على العدالة، وتستمر حالة التقدم حتى لو تم تحديث الصفحة. يتم تصحيح الأسئلة الموضوعية على خادم النظام فور التسليم مع عرض الإجابات والتحليلات فورًا. تُظهر لوحة تحكم المعلم النتائج مرتبة حسب الدرجات مع تفاصيل لكل سؤال. يتم حذف بيانات الامتحان تلقائيًا بعد 7 أيام لحفظ الخصوصية. مكافحة الإساءة: 20 عملية نشر لكل عنوان IP يوميًا، ويتم تعليق الامتحان تلقائيًا عند وصول 3 بلاغات من عناوين IP مختلفة. **صورة Docker مستقلة بالكامل** — يعمل ترحيل الامتحانات عبر الإنترنت على SQLite بدون أي اعتماد على موقع العرض التوضيحي.

- **إطلاق الامتحانات من بنوك الأسئلة** — تجميع الامتحانات من بنوك محلية متعددة مع تحديد عدد الأسئلة والنقاط لكل نوع؛ وضبط العنوان ووقت البدء والمدة
- **رمز من 6 أرقام + رابط الامتحان** — ينضم الطلاب من متصفح أي جهاز، دون الحاجة إلى تثبيت تطبيق
- **جلسات موقوتة** — عد تنازلي محلي مع تقديم تلقائي؛ يتكيف التقدم مع إعادة تحميل الصفحة (استكمال الامتحان من حيث توقفت)
- **تقييم فوري** — تصحيح الأسئلة الموضوعية على الخادم مع عرض الإجابات والشرح فور التسليم؛ وتخزين النتائج محليًا للمراجعة في أي وقت
- **لوحة تحكم المعلم** — نتائج مرتبة حسب الدرجة مع تفاصيل الإجابة لكل سؤال؛ مخزنة محليًا مؤقتًا بحيث يتم جلب النتائج مرة واحدة فقط بعد انتهاء الامتحان؛ يمكن للمعلمين حذف الامتحان في أي وقت (يمحو النتائج ويمنع دخول الطلاب فورًا)
- **ترحيل يراعي الخصوصية** — تعيش بيانات الامتحان على Cloudflare D1 لمدة 7 أيام كحد أقصى قبل الحذف التلقائي؛ لا يتم إرسال الإجابات إلى الطلاب قبل التسليم
- **مكافحة الإساءة** — 20 عملية نشر لكل IP يوميًا؛ بلاغات الطلاب بضغطة زر تقوم بتعليق الامتحان تلقائيًا عند وصول 3 بلاغات من IP مختلفة؛ يمكن للمشرفين المراجعة أو الإعادة أو الحذف من صفحة `#/admin`
- **استضافة ذاتية بالكامل** — توفر صورة Docker نفس ترحيل الامتحانات (SQLite)، دون الاعتماد على موقع العرض التوضيحي؛ اضبط `ADMIN_TOKEN` لتأمين صفحة المشرف (الافتراضي `pass`، ويجب تغييره عند أول زيارة لصفحة `#/admin`)

### 🔍 modes البحث — اعثر على الإجابات بسرعة

ابحث في بنوك الأسئلة المحلية عن طريق كتابة أو لصق السؤال — يوفر الذكاء الاصطناعي الاختياري إجابات وشروحًا. **البحث بالصور** يستخدم OCR المحلي على الجهاز للتعرف على الأسئلة من الكاميرا أو الصور المرفوعة (تتم المعالجة محليًا في متصفحك دون رفع شيء). **البحث المباشر بالكاميرا** يوجه الكاميرا نحو شاشة أو ورقة ويراقب الذكاء الاصطناعي الأسئلة المطابقة في الوقت الفعلي. **البحث عبر تسجيل الشاشة** يتيح لك رسم إطار التقاط فوق أي نافذة — يراقبه الذكاء الاصطناعي ويعرض الإجابات في نافذة عائمة (Windows/macOS/Linux/Android؛ غير متاح على iOS بسبب قيود النظام).

- **البحث النصي** — اكتب أو الصق سؤالاً للعثور على التطابقات في بنوكك المحلية، مع إمكانية الإجابة بالذكاء الاصطناعي
- **البحث بالصور** — التقط أو ارفع صورة لسؤال؛ يعمل التعرف الضوئي على الحروف (OCR) محليًا في متصفحك بدون رفع
- **البحث المباشر عبر الكاميرا** — وجه كاميرتك إلى الشاشة أو الورقة؛ يراقب الذكاء الاصطناعي الأسئلة ويطابقها في الوقت الفعلي
- **البحث عبر تسجيل الشاشة** — ارسم إطار التقاط فوق أي نافذة؛ يراقب الذكاء الاصطناعي ويطابق الأسئلة مباشرة مع تراكب إجابات عائم (Windows / macOS / Linux / Android؛ غير متوفر على iOS بسبب قيود النظام)

### 🌐 عبر المنصات والخصوصية — بياناتك على جهازك

يعمل Exameow على **Windows و macOS و Linux و Android و Web** (و iOS عبر البناء الذاتي). قم بنشر إصدار الويب بـ **أمر Docker واحد**. يتم تخزين جميع بنوك الأسئلة وسجلات التدريب وتاريخ الأسئلة الخاطئة محليًا — لا يتم تحميل أي شيء إلى خادم إلا إذا اخترت استخدام ترحيل الامتحانات عبر الإنترنت. تم تشفير مفاتيح API باستخدام **AES-256-GCM** على سطح المكتب. تكتشف واجهة المستخدم تلقائيًا لغة النظام (الصينية / الإنجليزية) مع التبديل بضغطة زر.

- **سطح المكتب والهاتف المحمول** — Windows و macOS و Linux و Android (بناء ذاتي لـ iOS)
- **استضافة الويب الذاتية** — نشر بأمر Docker واحد
- **المحلي أولاً** — تظل بنوك الأسئلة وسجلات التدريب والأسئلة الخاطئة على جهازك؛ مفاتيح API مشفرة بـ AES-256-GCM على سطح المكتب
- **واجهة ثنائية اللغة** — اكتشاف تلقائي للغة النظام (الصينية / الإنجليزية)، وتبديل بنقرة واحدة

### Docker (مستضاف ذاتيًا)

```bash
git clone https://github.com/heshengtao/exameow.git
cd exameow

# بناء الواجهة الأمامية
cd frontend && pnpm install && pnpm build && cd ..

# تكوين مزود الذكاء الاصطناعي
export AI_ENDPOINT=https://api.openai.com/v1
export AI_API_KEY=sk-your-key-here
export AI_MODEL=gpt-4o

# البناء والتشغيل
docker compose up -d --build
```

افتح `http://localhost:3000`.

> **🔐 رمز المشرف (مطلوب لإدارة الامتحانات عبر الإنترنت):** صفحة المشرف على `http://localhost:3000/#/admin` محمية بواسطة `ADMIN_TOKEN`. إذا لم تقم بضبطه، فسيكون افتراضيًا **`pass`** وستكون **مجبورًا على تغييره عند تسجيل الدخول الأول** قبل القيام بأي شيء. لتخطي ذلك، اضبطه عند بدء التشغيل:
>
> ```bash
> ADMIN_TOKEN=your-strong-token docker compose up -d --build
> ```
>
> يظل الرمز المتغير محفوظًا في وحدة التخزين `exameow-data` (`/app/data/admin_token.txt`) عبر عمليات إعادة تشغيل الحاوية. يتم تخزين بيانات الامتحان (SQLite) في نفس وحدة التخزين.

### Docker (صورة جاهزة)

```bash
docker pull ailm32442/exameow:latest
docker run -d -p 3000:3000 \
  -e AI_ENDPOINT=https://api.openai.com/v1 \
  -e AI_API_KEY=sk-your-key-here \
  -e AI_MODEL=gpt-4o \
  -e ADMIN_TOKEN=your-strong-token \
  -v exameow-data:/app/data \
  ailm32442/exameow:latest
```

إذا لم يتم تعيين `ADMIN_TOKEN`، فسيتم تعيينه افتراضيًا على `pass` ويجب تغييره في الزيارة الأولى لـ `/#/admin`.

| `AI_MODEL` | `gpt-4o` | النموذج الافتراضي للاستخدام |
| `PORT` | `3000` | منفذ استماع الخادم |
| `STATIC_DIR` | `/app/static` | دليل الملفات الثابتة |

| `ADMIN_TOKEN_FILE` | `/app/data/admin_token.txt` | مكان حفظ رمز المشرف المغير |

| الطريقة | المسار | الوصف |

## البنية الهندسية

يعتمد Exameow على **بنية من ثلاثة خوادم خلفية** تتشارك واجهة أمامية واحدة مبنية بـ Vue 3. يكتشف تطبيق الصفحة الواحدة (SPA) المنصة تلقائيًا أثناء التشغيل ويوجه الطلبات إلى الخلفية المناسبة:

- **Tauri (سطح المكتب/الهاتف المحمول)**: تستدعي أوامر Rust في `src-tauri/` مكتبة Rust الأساسية مباشرة
- **Cloudflare Workers**: يستدعي كود TypeScript في `workers/` خدمات Cloudflare AI + D1 لترحيل الامتحانات
- **Axum (استضافة ذاتية/Docker)**: خادم Rust HTTP في `packages/server/` مع SQLite لترحيل الامتحانات

تستقر المنطق الأساسي (تحليل الملفات، عميل الذكاء الاصطناعي، إنشاء الامتحانات، التصدير) في حزمة Rust المشتركة `packages/core/`، وتم تكرارها في TypeScript لمسار Workers.

## الأسئلة الشائعة

### كيف يمكنني إنشاء أسئلة امتحان من ملف PDF؟

قم بتحميل ملف PDF الخاص بك عبر السحب والإفلات في [موقع العرض التوضيحي](https://exam.superagentparty.com/) أو في تطبيق سطح المكتب. حدد أنواع الأسئلة (اختيار من متعدد إجابة واحدة/إجابات متعددة، صواب/خطأ، إكمال الفراغات، إجابة قصيرة)، واضبط عدد الأسئلة والصعوبة، ثم انقر فوق إنشاء. يقرأ الذكاء الاصطناعي مستندك ويولد الأسئلة في ثوانٍ. يمكن تصدير النتائج كملفات XLSX أو CSV.

### هل Exameow مجاني حقًا؟

نعم. Exameow مفتوح المصدر بموجب رخصة Apache 2.0 ومجاني بنسبة 100%. لا توجد خطط مدفوعة أو إصدارات شركات أو قيود على الميزات. يوفر موقع العرض التوضيحي إنشاءً مجانيًا بالذكاء الاصطناعي (مع حدود حصة يومية من الفئة المجانية لـ Cloudflare). تتطلب تطبيقات سطح المكتب/الهاتف المحمول مفتاح API الخاص بك، والذي تدفعه لمزود الذكاء الاصطناعي مباشرة — لا يفرض عليك Exameow أي رسوم.

### هل يمكنني استخدام Exameow بدون اتصال بالإنترنت؟

نعم. تعمل تطبيقات سطح المكتب والهاتف المحمول بدون اتصال بالإنترنت تمامًا. يتم تخزين بنوك الأسئلة وسجلات التدريب وتاريخ الأسئلة الخاطئة محليًا. تحتاج فقط إلى اتصال بالإنترنت عند الاتصال بـ API الذكاء الاصطناعي لإنشاء الأسئلة.

### ما هي نماذج الذكاء الاصطناعي التي يدعمها Exameow؟

يعمل أي API متوافق مع OpenAI: مثل OpenAI (GPT-4o, GPT-4, GPT-3.5) و DeepSeek و Qwen و GLM والنماذج المستضافة ذاتيًا عبر Ollama أو ما يماثلها. يمكنك أيضًا استخدام Cloudflare AI المجاني المدمج في موقع العرض التوضيحي.

### كيف تعمل ميزة الامتحان عبر الإنترنت؟

ينشر المعلمون الامتحانات من بنوك الأسئلة المحلية برمز مكون من 6 أرقام. ينضم الطلاب من أي متصفح باستخدام هذا الرمز أو رابط مشارك. الامتحان موقوت مع تقديم تلقائي. يتم تصحيح الأسئلة الموضوعية فورًا. يتم حذف بيانات الامتحان تلقائيًا بعد 7 أيام. يحصل المستضيفون ذاتيًا على نفس الترحيل عبر Docker.

### هل بياناتي خاصة وآمنة؟

نعم. افتراضيًا، تظل جميع البيانات (بنوك الأسئلة، سجلات التدريب، مفاتيح API) على جهازك. تم تشفير مفاتيح API باستخدام AES-256-GCM. الاستثناء الوحيد هو بيانات الامتحان عبر الإنترنت، والتي يتم تخزينها مؤقتًا على Cloudflare D1 (حذف تلقائي بعد 7 أيام) أو على SQLite المستضاف ذاتيًا.
